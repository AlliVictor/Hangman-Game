# Hangman-Game
A text-based implementation of the classic Hangman game in Java.

-------------------------------------------------------------------

## How to Play
1. From a preset set of words, the program randomly chooses a word.
2. One by one, the player must guess each letter in the word.
3. A portion of the hangman is drawn for every wrong guess. To finish the hangman, the player has to guess the word.
4. The game goes on Until the player correctly guesses the word or runs out of attempts.

------------------------------------------------------------------

## How to Run
1. Clone this repository or download the source code files.
2. Open a command prompt or terminal and navigate to the project directory.
3. Compile the Java source file by running the following command:
[javac HangmanGame.java]
4. Run the compiled program using the following command:
[java HangmanGame]
